# 👑 Tsarev Bot

Современный Discord-бот для RP/игрового сервера на Python 3.11+ и discord.py 2.x.

## ✨ Возможности

- 📨 **Заявки** — модальные формы, кнопки `Принять / Взять на рассмотрение / Вызвать на обзвон / Отклонить`, история, несколько типов заявок (семья, фракция, повышение, кастом).
- 📜 **Контракты** — создание, статусы `активен/выполнен/отменён`, награды, выдача ролей.
- 📦 **Учёт** — имущество, авто, предметы, категории, поиск, журнал, экспорт JSON.
- 🔥 **Сборы «Плюсы»** — кнопка `+`, **строгая очередь по порядку входа**, основной состав + запас, MCL/ВЗМ/контракты/кастом.
- 🔊 **Временные голосовые каналы** — авто-создание, авто-удаление, панель управления (имя, лимит, lock/unlock, kick).
- 🗒️ **Логи** — вход/выход, удаление и редактирование сообщений, voice activity, баны, роли, создание/удаление каналов.
- 🎚️ **Роли по кнопке** — toggle ролей, мультивыбор, эмодзи.
- 🎨 **Конструктор Embed** — modal-форма с заголовком, описанием, цветом, картинкой, footer.
- 📡 **Мониторинг Majestic RP** — авто-обновление статуса серверов.
- 💤 **AFK** — статус, причина, авто-снятие, уведомления при упоминании, время отсутствия.

## 🚀 Запуск

1. Python 3.11+
2. `pip install -r requirements.txt`
3. `cp .env.example .env` и заполните `DISCORD_TOKEN`
4. `python main.py`
